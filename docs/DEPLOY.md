# نشر الموقع على GitHub Pages

دليل خطوة بخطوة لنشر الموقع على الإنترنت ومشاركة رابطه مع أي شخص.

---

## قبل أن تبدأ: ماذا سيرى صديقك؟

الموقع **ثابت**، وبياناته (اسمك، مشاريعك، رسائلك) تُحفظ في `localStorage`
**داخل متصفحك أنت**، ولا تُرفع مع الملفات.

- ما يُرفع: `index.html` و`css/` و`js/` و`assets/`.
- ما يراه صديقك: البيانات الافتراضية المكتوبة في `js/app.js` داخل `DEFAULTS`.
- لذلك إن عدّلت بياناتك من لوحة التحكم محلياً فلن تظهر له.

**لجعل صديقك يرى بياناتك الحقيقية:** عدّل `DEFAULTS` في `js/app.js` يدوياً
(أو أخبرني لأضيف آلية تحميل بيانات من ملف `data.json`).

---

## الطريقة أ — الرفع من واجهة GitHub (بلا أدوات ولا أوامر)

1. أنشئ حساباً على [github.com](https://github.com) إن لم يكن لديك.
2. اضغط **+** أعلى اليمين ← **New repository**.
3. املأ:
   - **Repository name**: `my-portfolio`
   - **Visibility**: `Public` (مجاني، وشرط لعمل Pages مجاناً)
   - لا تضف README ولا .gitignore (المشروع يملكها).
4. اضغط **Create repository**.
5. في صفحة المستودع الفارغة اضغط **uploading an existing file**.
6. اسحب **محتويات** مجلد `my_portfolio` (لا المجلد نفسه): يجب أن يظهر
   `index.html` في الجذر مباشرة، ومعه `css/` و`js/` و`assets/`.
7. اضغط **Commit changes**.

> ⚠️ إن رفعت المجلد كطبقة إضافية (`my_portfolio/index.html`) ستصبح الصفحة
> الرئيسية فارغة. `index.html` يجب أن يكون في جذر المستودع.

## الطريقة ب — GitHub Desktop (الأفضل للتحديثات المتكررة)

1. نزّل [GitHub Desktop](https://desktop.github.com/) وسجّل الدخول.
2. **File → Add local repository** ← اختر مجلد `my_portfolio`.
3. إن طلب إنشاء مستودع: **create a repository** ← اضغط **Publish repository**
   (أزل علامة Private).
4. بعد النشر، أكمل خطوات [تفعيل Pages](#تفعيل-github-pages) أدناه.

للتحديث لاحقاً: عدّل الملفات ← يظهر التغيير في التطبيق ← اكتب وصفاً ←
**Commit to main** ← **Push origin**. الموقع يُحدَّث تلقائياً بعد دقيقة.

## الطريقة ج — سطر الأوامر (git)

```bash
cd "C:\Users\ASUS\Documents\deepseek-harness\default-workspace\build"

git init
git add .
git commit -m "Initial portfolio site"
git branch -M main

git remote add origin https://github.com/USERNAME/my-portfolio.git
git push -u origin main
```

> استبدل `USERNAME` باسم حسابك. عند الطلب، استخدم **Personal Access Token**
> ككلمة مرور (GitHub لم يعد يقبل كلمة مرور الحساب).

## تفعيل GitHub Pages

1. في صفحة المستودع: **Settings** (أعلى اليمين).
2. من القائمة اليسرى: **Pages**.
3. تحت **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. اضغط **Save**.
5. انتظر 1–3 دقائق، ثم حدّث الصفحة. سيظهر الرابط:

```
https://USERNAME.github.io/my-portfolio/
```

هذا هو الرابط الذي ترسله لصديقك.

**إن سمّيت المستودع `USERNAME.github.io`** يصبح الرابط
`https://USERNAME.github.io/` بلا اسم مستودع.

---

## التحقق من نجاح النشر

- تبويب **Actions** في المستودع: يجب أن ترى مهمة `pages build and deployment`
  بلون أخضر.
- إن ظهرت 404: راجع أن `index.html` في الجذر، وأن Pages مضبوط على `main / root`.
- أول نشر قد يتأخر دقيقتين إضافيتين بسبب ذاكرة التخزين المؤقت (CDN).
  جرّب `Ctrl + F5`.

---

## التحديث لاحقاً

أي `commit` جديد على فرع `main` يعيد نشر الموقع تلقائياً. لا حاجة لأي إعداد
إضافي.

إن عدّلت التصميم ولا يظهر التغيير فوراً: افتح الصفحة في نافذة خاصة
(`Ctrl + Shift + N`) لتجاوز الكاش.

## ملاحظات مهمة خاصة بهذا الموقع

| الأمر | التفصيل |
| --- | --- |
| **الخط** | يُحمَّل من Google Fonts، يحتاج اتصالاً بالإنترنت |
| **الترجمة التلقائية** | تحتاج إنترنت؛ تستخدم خدمة عامة مجانية |
| **الصور المرفوعة** | تُحفظ Base64 في متصفحك فقط، لا تُرفع للمستودع |
| **الرسائل** | محفوظة محلياً عندك؛ الزائر الذي يرسل رسالة عبر موقعه لا يراها هو، بل تبقى في متصفحه |
| **الروابط** | كل المسارات نسبية (`css/…`, `js/…`)، لذا يعمل الموقع على Pages بلا تعديل |
| **واتساب** | الرابط `https://wa.me/963994845656` يعمل من أي مكان |

> ⚠️ لأن الرسائل تُحفظ في متصفح الزائر، فإن نموذج «تواصل معي» لا يوصلك
> فعلياً عند النشر — إلا إذا أضفت خدمة خلفية (مثل Formspree أو Google Forms).
> حالياً الوسيلة الفعلية للتواصل هي زر واتساب.

## بديل أسرع من GitHub Pages

إن أردت رابطاً خلال دقيقة بلا مستودع:

- [Netlify Drop](https://app.netlify.com/drop): اسحب المجلد كاملاً ويظهر رابط فوري.
- [Cloudflare Pages](https://pages.cloudflare.com/): ربط مستودع أو رفع مباشر.

كلاهما يدعم مجلداً ثابتاً بلا إعدادات بناء.
